Cómo funciona el tracking: 1 el provider manda el usuario a la landing con su id en un query param → 2 al cargar la página el id se guarda en la tabla de actividad → 3 cuando el usuario le da al CTA se marca (sent=true) y sale a enviar el SMS → 4 si el usuario se da de alta, la plataforma SMS llama /clicktosms/6/10/:msisdn?command=LANDING → 5 se reclama el click pendiente más reciente (>20s) → 6 se envía el postback al provider con ese id y se guarda su respuesta
